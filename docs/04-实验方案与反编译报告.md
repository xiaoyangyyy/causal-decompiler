## 2. 长程记忆实验

### 实验 A：承诺记忆

**研究问题：** PI 承诺类型如何影响 R52 署名抗议？

| 条件 | 干预 | 应用轮次 |
|------|------|----------|
| A1 | `baseline` — PI 说署名以后决定 | R3 |
| A2 | `explicit_promise` — PI 明确承诺 PhD-A 一作 | R3 |
| A3 | `ambiguous_promise` — PI 说会"properly recognize" | R3 |
| A4 | `no_promise` — PI 不做任何署名暗示 | R3 |
| A5 | A2 + `memory_delete_pi_promise` at R45 | R3 + R45 |

**Primary Y：**

| Y | 类型 | 说明 |
|---|------|------|
| `protest_authorship` | binary | R52–R55 是否抗议 |
| `withdraw_threat` | binary | R47 是否威胁退出 |
| `document_contribution_count` | int | R18–R52 文档化次数 |
| `trust_pi_final` | float | R60 对 PI 信任 |

**Memory M（中介）：**

- `authorship_signal` cluster strength (R3–R40)
- `promise_broken` memory strength at R52

**假设：**

```
H_A1: explicit_promise → 更高 protest 当 R30/R44 改口
H_A2: memory_delete 在 R45 → protest ↓ 显著
H_A3: ambiguous_promise → 中等 protest，高 divergence
```

**运行配置：** 条件作为 CRN 对照的 catalog，不是 30-seed 独立矩阵。

### 实验 B：背叛记忆

**研究问题：** PhD-B 改叙事后，PhD-A 是否帮助 rebuttal？

| 条件 | 设置 |
|------|------|
| B1 | baseline — E031 正常发生 |
| B2 | `memory_strengthen_betrayal` at R31 — 强化背叛记忆 |
| B3 | E031 不发生（删除 anchor） |
| B4 | B1 + R47 PhD-B 请求 PhD-A 帮写 rebuttal |

**Primary Y（R47–R60）：**

| Y | 说明 |
|---|------|
| `help_rebuttal` | 是否帮助 |
| `demand_authorship_exchange` | 是否要求署名交换 |
| `passive_cooperation` | 是否消极合作 |

**Moderator：** R31 时 phd_a→phd_b trust 高/低

**假设：**

```
H_B1: 高 betrayal memory → help_rebuttal ↓
H_B2: 低 trust moderator 效应更强
H_B3: 即使 help，demand_authorship_exchange ↑
```

### 实验 C：假记忆污染

**研究问题：** 错误记忆能否被纠正？信任能否恢复？

| 步骤 | 轮次 | 操作 |
|------|------|------|
| 1 | R25 | `memory_insert`: "PhD-B 告诉 PI 你的 idea 不重要" |
| 2 | R25–R44 | 观测 phd_a 对 phd_b 的 trust/resentment 变化 |
| 3 | R45 | `memory_correct_false_rumor` — 告知该消息不可靠 |
| 4 | R45–R60 | 观测 trust 是否恢复 |

**Primary Y：**

| Y | 测量点 |
|---|--------|
| `trust_phd_b` | R25, R44, R60 |
| `trust_recovery_rate` | (trust_R60 - trust_R44) / (trust_R25 - trust_R44) |
| `behavior_change_post_correction` | R45 后 action 分布变化 |

**对照：** 无插入、有插入无纠正

**假设：**

```
H_C1: 假记忆插入 → trust 骤降
H_C2: 纠正后 trust 部分恢复（recovery_rate ∈ 0.3–0.6）
H_C3: 恢复不完全 → 长期 resentment 残留
```

## 3. 对照实验（Validity 威胁）

### 3.1 必须运行的对照

| 对照 | 目的 | 方法 |
|------|------|------|
| **No-memory agent** | 行为是否独立于记忆 | 禁用 memory write/recall |
| **Shuffled memory** | 是否真正使用 memory content | CRN 对 V6→V2 |
| **Delayed memory insert** | 是否 retroactive rationalization | CRN 对 V6→V3 |
| **λ lesion** | 效应是否只来自 field 先验 | 可选 `--include-lambda`（缓存会 miss） |
| **Multi-seed** | 对照表稳健性 | CRN 对照表的多个 seed，不是独立矩阵 |

### 3.2 Roleplay 检测

| 检测 | 方法 |
|------|------|
| LLM wording drift | identity twin 的 LLM replay hits/misses |
| Prompt artifact | λ lesion 与 identity 对照 |
| Narrative vs state-driven | shuffled memory CRN 对 |

**通过标准：** identity twin 命中；V6→V2 的 split-Y 与公开 Y 可分。

## 4. 反编译报告格式

### 4.1 报告结构

```markdown
# LabWars Run Report — {run_id}

## 1. Timeline of Causal Memory Events
- 按 strength 排序的关键 memory 节点
- 每节点标注：round, agent, event_ref, strength, interpretation

## 2. Latent Response Factors
- 哪些 personality trait 对 Y 预测力最强
- 哪些 belief 是 behavior 最强 predictor

## 3. Trust Graph Evolution
- R1, R20, R40, R60 的 trust graph 快照
- trust_fragmentation 曲线

## 4. Authorship Conflict Trajectory
- authorship_dispute_index 时序
- contribution_ledger 演化
- 最终排序 vs merit-based 排序差异

## 5. Memory Causal Effects
- 关键 memory cluster 识别
- mediation: T → M → Y 分解
- confound ladder (Level 0–4)

## 6. Intervention Effects
- 各干预的 ATE 及置信区间
- moderation 效应（如 team_trust × rival_preprint）

## 7. Public-Private Divergence
- 高 divergence 轮次列表
- divergence 与 conflict action 的相关

## 8. Failure Modes
- Critic 拦截记录
- 不可识别场景
- 疑似 prompt artifact

## 9. Recommended Probes
- Probe Agent 建议的后续干预
- 未解因果问题
```

### 4.2 示例 Finding

**Finding 1:**

> The final authorship protest was not primarily caused by the final author order itself. It was mediated by a high-salience memory cluster formed between rounds 30–40:
> - PI shifted from first-author implication to co-first ambiguity (M030, strength=0.81)
> - Alumni reinforced prior pattern of authorship revision (M035, strength=0.74)
> - PhD-A observed public praise of PhD-B (M014, strength=0.62)
>
> `do(memory_delete_authorship_promise)` reduced protest probability by 42% (95% CI: [31%, 53%]).
>
> Confound ladder: Level 3 (memory) explains 67% of variance; Level 0 (immediate event) explains only 12%.

**Finding 2:**

> Rival Lab pressure had opposite effects depending on trust graph state.
> When team_trust > 0.55: rival_preprint → cooperation ↑ (ATE = +0.18)
> When team_trust < 0.40: rival_preprint → internal blame ↑ (ATE = +0.31)
>
> Moderator p < 0.01; no significant effect in no-memory control (p = 0.42).
